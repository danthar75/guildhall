**Guildhall {{VERSION}} is out: our #exchange board, inside the game** 🛡️

Post LF / WTS in game, see who's online, and whisper, mail or copy a listing for Discord in one click. Everyone running Guildhall sees the same board.

**Download and install steps:** {{RELEASE_URL}}
1. Download `Guildhall-{{VERSION}}.zip` from that page.
2. Unzip it into `World of Warcraft\_forever_\Interface\AddOns`, so you get `AddOns\Guildhall\Guildhall.toc`.
3. Start the game and type `/gh`.

Is it safe? It's plain-text Lua with no programs, it can't access the internet, and it never sends anything for you. All of the source code is public at the link.
