**Guildhearth {{VERSION}} (beta) is out: our #exchange board, inside the game** 🛡️

It is a beta: we are testing it here in Emergence first, so expect rough edges and tell @Dor what breaks.

Post LF / WTS in game, see who's online, and whisper, mail or copy a listing for Discord in one click. Everyone running Guildhearth sees the same board.

**Download and install steps:** {{RELEASE_URL}}
1. Download `Guildhearth-{{VERSION}}.zip` from that page.
2. Unzip it into `World of Warcraft\_forever_\Interface\AddOns`, so you get `AddOns\Guildhearth\Guildhearth.toc`.
3. Start the game and type `/gh`.

Is it safe? It's plain-text Lua with no programs, it can't access the internet, and it never sends anything for you. All of the source code is public at the link.
